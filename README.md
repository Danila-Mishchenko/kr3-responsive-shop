# Контрольная работа №3. Адаптивный интернет-магазин


Тема работы — адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта.

## Практическая работа №12

В отдельный репозиторий `kr3-responsive-shop` перенесены пять страниц магазина из КР №1.
Открыть магазин локально можно со страницы `index.html`.

- На каждой странице есть `viewport`. Файл `css/responsive.css` подключён после `css/style.css`.
- Основные стили рассчитаны на телефон. Медиазапросы с `min-width` меняют раскладку с 768 и 1024 px.
- Навигация переносится по строкам. Отступы и заголовок первого экрана подстраиваются под ширину.
- Карточки располагаются в одну, две или три колонки. Фильтр каталога на телефоне находится над товарами, на широких экранах закрепляется сбоку.
- На странице товара используется `picture` с двумя вариантами WebP и запасным SVG. Браузер выбирает файл через `srcset` и `sizes`, а CSS ограничивает ширину изображения.
- Поля заявки идут в одну колонку на телефоне и в две с 768 px. Модальное окно помещается в экран и прокручивается внутри.
- Обе таблицы сохраняют свою структуру. На телефоне прокручиваются только их контейнеры, в том числе с клавиатуры.

## Практические работы №13 и №14

Для декоративной заглушки задан пустой `alt`. Текущий пункт меню отмечен через `aria-current`.
Области прокрутки таблиц подписаны через их заголовки. Подписи модального окна и связь полей с ошибками сохранены.

В Chrome через DevTools Protocol проверены все пять страниц на ширинах 360, 430, 768, 1024 и 1440 px.
Общего горизонтального скролла нет. Проверены сетка, выбор файлов изображения при разной ширине и плотности пикселей, раскладка и валидация формы, клавиатурная прокрутка таблиц и закрытие модального окна по Escape.

Lighthouse оценил доступность каждой из пяти страниц на 100 из 100. HTML-отчёты сохранены в папке `reports/`.

## Практическая работа №15

В `js/data.js` описан «Товар 2». В `js/product-demo.js` реализованы форматирование цены, расчёт суммы скидки и итоговой цены, определение наличия и формирование описания. Результаты видны в консоли при открытии главной страницы. Для цены 1500 ₽ и скидки 20% сумма скидки составляет 300 ₽, итоговая цена — 1200 ₽.

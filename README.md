## Практическая работа №12

В отдельный репозиторий `kr3-responsive-shop` перенесены пять страниц магазина из КР №1.
Открыть магазин локально можно со страницы `index.html`.

- На каждой странице есть `viewport`. Файл `css/responsive.css` подключён после `css/style.css`.
- Основные стили рассчитаны на телефон. Медиазапросы с `min-width` меняют раскладку с 768 и 1024 px.
- Навигация переносится по строкам. Отступы и заголовок первого экрана подстраиваются под ширину.
- Карточки располагаются в одну, две или три колонки. Фильтр каталога на телефоне находится над товарами, на широких экранах закрепляется сбоку.
- На странице товара используется `picture` с двумя вариантами WebP. Браузер выбирает файл через `srcset` и `sizes`, а CSS ограничивает ширину изображения.
- Поля заявки идут в одну колонку на телефоне и в две с 768 px. Модальное окно помещается в экран и прокручивается внутри.
- Обе таблицы сохраняют свою структуру. На телефоне прокручиваются только их контейнеры, в том числе с клавиатуры.

## React, JavaScript и Go

- **React** управляет карточками, фильтрами, результатами, пагинацией и избранным в каталоге. Исходный интерфейс в `src/catalog.jsx`. Избранное использует то же хранилище, что и отдельная страница избранного.
- **JavaScript** вычисляет цены и статусы товаров, сохраняет избранное и обрабатывает форму заявки. Список товаров редактируется в `data/products.json`.
- **Go** запускает локальный сервер в `server/main.go` и возвращает этот же список через `GET /api/products`. На GitHub Pages каталог использует данные, подготовленные при сборке.

### Как запустить и проверить

Для запуска Go нужен Go 1.22 или новее. Из корня проекта выполните:

```sh
go run ./server
```

- [Каталог с загрузкой из Go](http://127.0.0.1:8080/catalog.html?source=go). Над товарами появится сообщение о загрузке с сервера.
- [JSON со списком товаров](http://127.0.0.1:8080/api/products).

После правок в JSX, функциях JavaScript или в данных каталога пересоберите браузерные файлы:

```sh
npm ci
npm run build
```

Готовая сборка хранится в репозитории и используется на GitHub Pages. Для просмотра опубликованного сайта установка Node.js или Go не нужна.

## Учебный аккаунт и чат

- Регистрация и вход работают локально в браузере. Пароль хранится в виде PBKDF2-проверочного значения со случайной солью. Сеанс входа действует в текущей вкладке.
- В чате можно записать вопрос. Последние 100 сообщений сохраняются на устройстве, ответы консультанта не предусмотрены.
- В заявке каталога добавлены телефон, количество, самовывоз или доставка, адрес, способ связи, комментарий и согласие. Адрес обязателен при выборе доставки. Заявка демонстрационная.
